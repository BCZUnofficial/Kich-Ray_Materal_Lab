Material Lab 0.9.1 — исправление вкладок и поддержка альфа-канала

1. Закройте Material Lab.
2. Распакуйте содержимое ZIP в корень проекта рядом с KichRay_MaterialLab.sln, согласившись на замену файлов.
3. Откройте решение Visual Studio и пересоберите Release | x64.
4. Запустите новый MaterialLab.exe из bin/Release/x64. В заголовке должна быть версия 0.9.1. Сборка также обновляет assets/Preview.hlsl возле EXE.

Прозрачность включена по умолчанию. Настройки: Материал → Прозрачность diffuse (при необходимости прокрутите страницу вниз).
Авто: выбор маски/смешивания по альфе diffuse; Отсечение: листва/сетки; Смешивание: стекло.
Альфа bump/bump# сохраняет исходное назначение и не управляет прозрачностью.

Изменения накопительные: архив содержит обновлённые файлы версий 0.9.0 и 0.9.1.
Проверены кросс-сборка Windows x64 и переносимые тесты. Живой запуск интерфейса на Windows в этой среде не выполнен.
