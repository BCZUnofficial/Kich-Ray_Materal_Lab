Иконка Material Lab

MaterialLab.png — круглый герб ML с прозрачностью за пределами обода.
MaterialLab.ico — 32-битные изображения с альфа-каналом, размеры:
16, 20, 24, 32, 40, 48, 64, 96, 128 и 256 пикселей.

MaterialLab.rc и src/Resource.h задают ресурс IDI_MATERIALLAB (101).
MaterialLab.vcxproj компилирует его во всех конфигурациях Debug/Release,
Win32/x64. WinApp.cpp использует этот ресурс для большой и малой иконок окна.
Иконка встроена в EXE; внешний ICO для запуска не нужен.

Исходник: предоставленный пользователем ржавый радиационный герб ML.
Фон удалён встроенным ImageGen (background-extraction), затем изображение
преобразовано в многоразмерный ICO. Запрос обработки: убрать только чёрный
фон за пределами круглого металлического обода; сохранить ML, радиационный
знак, ржавчину, цвета, фактуру и тени внутри герба; использовать настоящий
альфа-канал и сглаженную границу без внешней тени.

Пересборка: KichRay_MaterialLab.sln → Сборка → Пересобрать решение.
CMake в этом проекте собирает только переносимые проверки, а не Windows EXE.
